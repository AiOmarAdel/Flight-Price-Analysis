# ✈️ Flight Price Analysis

A Data Analysis project exploring flight prices and the factors that influence them.

## 📊 Project Overview

This project analyzes flight booking data to understand pricing patterns and relationships between flight prices and different features such as:

* Airline
* Source City
* Destination City
* Departure Time
* Arrival Time
* Number of Stops
* Travel Class
* Flight Duration
* Days Left Before Departure

## 🎯 Objectives

* Explore and understand the dataset
* Clean and preprocess the data
* Analyze flight price distributions
* Compare prices across airlines
* Study the relationship between price and number of stops
* Analyze the effect of travel class on prices
* Investigate the relationship between days left and ticket prices
* Extract useful insights from the data

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📁 Dataset Features

| Feature          | Description                     |
| ---------------- | ------------------------------- |
| Airline          | Airline company                 |
| Flight           | Flight number                   |
| Source City      | Departure city                  |
| Departure Time   | Departure time category         |
| Stops            | Number of stops                 |
| Arrival Time     | Arrival time category           |
| Destination City | Arrival city                    |
| Class            | Travel class                    |
| Duration         | Flight duration                 |
| Days Left        | Days remaining before departure |
| Price            | Flight ticket price             |

## 🔎 Analysis

The notebook includes:

* Data inspection
* Missing values analysis
* Duplicate detection
* Descriptive statistics
* Univariate analysis
* Bivariate analysis
* Price distribution analysis
* Categorical feature analysis
* Correlation analysis
* Data visualizations

## 📈 Key Insights

The analysis investigates how flight prices vary according to airline, class, route, duration, stops, and booking time.
